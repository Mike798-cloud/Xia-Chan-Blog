# 夏蝉博客：2008备份修复（优化版）

纯前端叙事解谜游戏。直接打开 `index.html` 即可游玩，也可上传到 GitHub Pages。

## 本版保留的整体框架

- 旧压缩包解密开场
- 首页日记、留言板、相册/私密、小号博客、真相页五个板块
- 日期修复、火星文、草稿匹配、相册密码、日记密码、小号搜索、时间线和最终留言
- 线索、彩蛋、存档、音效和自愿一元支持

## 本版重点优化

- 每个阶段都有明确“当前修复目标”与三级免费提示
- 付款不再自动弹出，并明确与提示、章节、结局无关
- 毕业照信息支持普通点击，手机和平板不再依赖右键
- 草稿匹配逐项反馈；日期和时间线错误会指出具体位置
- 站内搜索支持常用同义词并提供可点击结果
- 自动存档静默，支持手动存档、JSON导入导出和旧存档迁移
- 结局不再依赖隐藏彩蛋数量
- 重新开始需要输入确认词，避免误删
- 完善手机、平板、键盘操作和减少动态效果适配
